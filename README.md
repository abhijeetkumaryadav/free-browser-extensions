## 📦 Install

**Option A — load unpacked (developers):**
1. Download or clone this repo.
2. Open `chrome://extensions`, enable **Developer mode**.
3. **Load unpacked** → pick the extension's folder.

**Option B — use the zip:** each extension folder contains a ready-to-load `.zip` (same contents).

Works on Chrome, Edge, Brave, Opera. Most also load in Firefox (Manifest V3).
