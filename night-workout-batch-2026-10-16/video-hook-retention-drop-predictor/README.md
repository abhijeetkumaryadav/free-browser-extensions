# Video Hook Signals — Heuristic Retention Scanner

Heuristic hook-signal scan for pasted video hook scripts. 100% local, no network.

**Honest scope:** this tool only scans for six hand-written word-list signals
(question opener, curiosity-gap words, specificity, direct address, payoff promise,
tight length). It **cannot predict retention, views, or performance**. A high score
does not mean a good hook; a low score does not mean a bad one.

## Features
- Paste your hook → 0–100 signal score ring with verdict
- Per-signal breakdown with matched examples and plain-language notes
- Signal guide tab explaining what each signal counts
- Personal notes tab (stored locally)

## Install (developer mode)
1. Open `chrome://extensions`, enable Developer mode.
2. Click "Load unpacked" and select this folder.

Works in Chrome and Edge; Firefox/Opera load the same unpacked folder.
