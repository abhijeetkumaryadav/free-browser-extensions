# Company Graveyard — Defunct-Company Memorial

Your memorial log for dead companies. Save companies (name, landing page URL, year died, your eulogy); each entry with a URL gets an **archive.org snapshot link you open yourself**.

## Honest scope
- **Your memorial — manual.** Nothing is fetched or checked automatically; the extension makes **zero network calls**.
- Archive links are plain anchors — only *your click* loads archive.org.

## Features
- Bury companies with eulogies, newest-first
- Per-entry archive.org snapshot links
- Search, per-company delete, clear-all with confirm
- 500-entry cap, all in `chrome.storage.local`

Permissions: `storage` only.
