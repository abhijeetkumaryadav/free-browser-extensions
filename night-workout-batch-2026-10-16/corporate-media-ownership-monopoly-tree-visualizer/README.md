# Media Ownership Tree — Concentration Guide & Notes

Learn how media ownership concentration works, then map parent/child media
organizations yourself.

## Honest scope

**Your notes — educational only.** This extension ships with zero ownership
data. The Learn tab explains concentration concepts and how to research
ownership; the My tree tab is a blank canvas where you add the outlets,
publishers, parent companies, and owners you discover, with "owned by" links
and your own notes. Ownership changes over time — date your notes and re-check
yearly.

## Features

- Learn tab: why ownership matters, how to read ownership chains, what
  concentration means, verify-everything reminder
- Add organizations with a role (outlet / publisher / parent / owner)
- Optional "owned by" parent link and free-text note per entry
- Search across names, parents, and notes; per-entry delete; clear-all
- Fully local: `chrome.storage.local`, no network calls

## Permissions

- `storage` — your organization notes

## Privacy

No accounts, no analytics, no remote calls.
