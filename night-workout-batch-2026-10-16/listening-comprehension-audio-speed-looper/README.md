# Listening Looper — Audio Speed & Loop Study Aid

Load a **local audio file** and study it at your own pace:

- **Variable speed 0.5×–1.5×** with a slider (great for slow listening comprehension)
- **A / B loop** — mark two points and repeat the section endlessly
- **Skip buttons** ±5s / ±10s and a seek bar with time readouts

Everything runs in the popup. The file plays from a same-session object URL —
**nothing is uploaded, stored, or transmitted**.

## Honest scope

Study aid only. This is not a transcription, translation, or comprehension tool.

## Files

- `manifest.json` — MV3, `storage` only
- `popup.html` / `popup.css` / `popup.js` — UI + playback engine
- `icons/` — generated 16/48/128 PNG icons

Install via `chrome://extensions` → Developer mode → Load unpacked.
