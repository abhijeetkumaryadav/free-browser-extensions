# Permaculture Companion Plant Matrix

A local companion-planting guide and garden-bed planner. Pick any of 26 common vegetables and herbs to see its **friends** and **foes** with plain-language explanations, then lay out a 3×3–5×5 raised bed and get instant conflict warnings when incompatible neighbours touch.

## Features

- **Matrix explorer** — friends/foes lists with reasons for 26 plants (tomato, basil, carrot, onion, garlic, beans, corn, squash, cucumber, lettuce, marigold, peppers, cabbage, potato, dill, fennel, radish, spinach, strawberry, sunflower, rosemary, thyme, peas, beets, hyssop)
- **Bed planner** — click cells to plant; neighbour conflicts (orthogonal) are flagged in red with a warning list
- **Persistent** — your bed layout is saved locally and restored on reopen
- **100% local** — no network requests, no accounts, no tracking

## Honest scope

The database reflects widely published traditional companion-planting guidance (e.g. the "carrots love tomatoes" tradition, three-sisters planting). These are **guidelines, not guarantees** — soil, climate, variety, and local pests matter more than any chart. The planner only checks direct (orthogonal) neighbours.

## Install

1. Open `chrome://extensions`, enable **Developer mode**
2. **Load unpacked** → select this folder (or drag in the `.zip` via "pack"/store upload)
3. Click the toolbar icon to open the 380px popup

## Permissions

- `storage` — saves your bed layout locally. That's it.

## Privacy

Nothing leaves your device. There is no server, no analytics, no remote code.
