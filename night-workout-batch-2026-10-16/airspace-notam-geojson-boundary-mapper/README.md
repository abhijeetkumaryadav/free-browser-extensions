# Airspace Notes — Class Guide & Boundary Log

Local airspace reference and personal boundary-note logbook.

## What it does
- **Class Guide tab** — ICAO-style A–G airspace class summaries (plain language).
- **My Notes tab** — log your own airspace boundary notes: area name, class,
  floor/ceiling, free-text notes (frequencies, entry reminders…). Search,
  newest-first, delete.

## Honest scope
- Educational only — not live NOTAMs, not official charts.
- Fully local — no network, no accounts. Notes persist in `chrome.storage.local`.

## Permissions
- `storage` — remember your notes.

## Files
- `manifest.json`, `popup.html`, `popup.css`, `popup.js`, `README.md`, `icons/`
