# Video Description Keyword Density — Heuristic Optimizer

Heuristic keyword-density table for pasted video descriptions. 100% local, no network.

**Honest scope:** this tool only *counts* words and repeated phrases. It cannot judge
ranking, SEO value, search intent, or writing quality. Use your own judgment.

## Features
- Paste a description → word / unique-word / character counts
- Top-terms table with per-100-word density bars and Normal / Elevated / High badges
- Duplicate 2–4 word phrase detection (repeated phrasing flags)
- Stopwords excluded from term counts
- Personal notes tab (stored locally)

## Install (developer mode)
1. Open `chrome://extensions`, enable Developer mode.
2. Click "Load unpacked" and select this folder.

Works in Chrome and Edge; Firefox/Opera load the same unpacked folder.
