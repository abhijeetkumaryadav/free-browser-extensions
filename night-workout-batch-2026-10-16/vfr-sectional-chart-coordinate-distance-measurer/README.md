# VFR Coordinate Distance Measurer

Enter two **lat/long pairs** and get the **great-circle distance** (nm / km / mi), **initial bearing**, and a simple **route sketch** on canvas.

## What it does

- Latitude ±90, longitude ±180 validation
- Haversine distance: km, nautical miles, statute miles
- Initial bearing in degrees + 16-wind compass point
- Equirectangular route sketch with a bearing arrow
- Remembers your last coordinate pair locally

## Honest scope

Great-circle math only — **not for navigation**. Real flight planning needs charts, airspace, terrain, winds aloft and NOTAMs. This is a pocket calculator for the numbers.

## Privacy

Fully local. Zero network. Nothing leaves the browser.
