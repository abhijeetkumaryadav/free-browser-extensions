# Flash Game Shelf — Preservation Links

Your personal list of historic Flash games. Save games (name, archive.org link, your notes); each entry's link opens in a new tab when **you** click it.

## Honest scope
- **Your list — links only.** No Flash emulation, no automatic fetching; the extension itself makes **zero network calls**.

## Features
- Add games with archive links and notes, newest-first
- Search, per-game remove, clear-all with confirm
- 500-entry cap, all in `chrome.storage.local`

Permissions: `storage` only.
