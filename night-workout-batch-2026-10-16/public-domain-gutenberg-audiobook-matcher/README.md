# Audiobook Shelf — My Public-Domain List

**Your audiobook list — not a matcher.** You save titles, authors, sources, statuses, and notes yourself. Nothing is matched automatically. The "Gutenberg search" buttons open a plain search page on gutenberg.org in a new tab — the extension itself makes zero network calls.

## Features
- Add titles with author, source URL, status (want / listening / finished), and notes
- Status counts across your whole list
- Per-title "Gutenberg search" and "Source" links (plain anchors)
- Search across titles, authors, notes
- Export / import as JSON

## Permissions
- `storage` — save your list locally

## Privacy
Fully local. No network calls, no analytics, no tracking.
