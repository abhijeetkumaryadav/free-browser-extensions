# Repo Graveyard — Abandoned Repo Memorial

A personal memorial for abandoned open-source repositories. Save repos with your own eulogies, search your graveyard, and keep your notes.

## Honest scope

**Your memorial — manual. Nothing is mined automatically; you record the repos yourself.**

- Save a repo: name, URL, and an optional eulogy.
- Per-repo **GitHub search** button opens a GitHub search in a new tab.
- The extension itself makes **zero network calls** — the links are plain anchors you open yourself.
- Personal notes log with search.
- Newest-first, case-insensitive search, per-grave delete, clear-all with confirm.

## How it works

1. Open the popup.
2. Go to **Bury one**, enter a name + URL (+ optional eulogy), click *Lay it to rest*.
3. On the **Graves** tab, click *GitHub search* to look the repo up on GitHub yourself.

## Permissions

- `storage` — saves your graves and notes locally in `chrome.storage.local`.

## Privacy

Everything stays on your device. No data leaves the extension. No accounts, no tracking, no remote code.
