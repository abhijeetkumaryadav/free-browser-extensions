# Ergo ROI Calculator

Estimate the payback period and lifetime value of ergonomic equipment (standing desks, chairs, monitor arms…) from **your own numbers**.

## How it works

1. Enter the equipment name, purchase cost, expected lifespan, and the daily comfort/productivity value **you** assign to it (in $/workday).
2. Click **Calculate ROI** — the extension computes:
   - **Yearly value** = daily value × 250 workdays
   - **Lifetime value** = yearly value × years
   - **Payback period** = cost ÷ yearly value
   - **Net gain** = lifetime value − cost
3. Results are saved to a local list (max 30 items) so you can compare purchases.

## Honest scope

- **Your numbers — estimates only.** The daily value is a subjective number you invent; the math is exact, the input is judgment.
- **Not financial advice.** This is a calculator, not an advisor.
- 100% local — `storage` permission only, no network, no analytics.

## Privacy

Nothing leaves your browser. Delete items individually or clear all anytime.
