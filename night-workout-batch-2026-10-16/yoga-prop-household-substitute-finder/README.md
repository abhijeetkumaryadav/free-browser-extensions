# Prop Swap — Yoga Prop Household Substitutes

A searchable reference of common yoga props and everyday household substitutes. 100% local, no network.

## What it does

- Searchable list of 12 yoga props (strap, block, bolster, blanket, cushion, wheel, eye pillow, sandbag, mat, wedge, trapeze, massage ball)
- Each entry shows a primary household substitute, a usage note, and alternatives
- Last search query remembered locally

## Honest scope

- **Reference list only — not coaching.** Substitutes are suggestions, not instruction.
- The trapeze entry explicitly warns that there is no safe household substitute — do not improvise load-bearing equipment.
- Always test a substitute for stability before use.

## Files

- `manifest.json` — Manifest V3
- `popup.html` / `popup.css` / `popup.js` — UI + bundled reference engine
- `icons/` — generated PNG icons

## Permissions

- `storage` — remembers the last search query
