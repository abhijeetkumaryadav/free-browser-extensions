# Property Notes — Zoning & Boundary Sketch

Manual property record keeper. Store your own property notes — address, lot details,
zoning notes from your own research, a documents checklist — and draw a rough
boundary sketch per property.

## Honest scope

- **Your own notes only.** This extension is a personal notebook. It is **NOT**
  official zoning data, NOT a municipal records viewer, and NOT a survey tool.
- There is no live connection to any municipality, registry, or map service.
- Always verify anything important (zoning, boundaries, permits) with your local
  municipality or a licensed surveyor.

## Features

- Add / edit / delete properties with lot details and zoning notes
- Documents checklist (6 defaults + your own custom items)
- Freehand boundary-sketch canvas per property (saved as PNG, rough sketch only)
- Everything stored in `chrome.storage.local` — 100% local, zero network

## Permissions

- `storage` — save your properties, checklists, and sketches on this device.
