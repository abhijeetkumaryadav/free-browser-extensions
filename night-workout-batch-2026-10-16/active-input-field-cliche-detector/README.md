# Cliché Detector

Scans the active text field (or pasted text) against a bundled list of ~140 common English clichés and reports every match with counts.

## How to use

1. Click inside any text field on a page (or select some text).
2. Open the popup and click **Scan active field** — matches appear with occurrence counts.
3. Alternatively paste text into the box and click **Scan pasted text**.
4. **Clear marks** resets the results.

## Honest scope

- **Bundled phrase list only — not AI.** Matching is plain substring matching with word boundaries.
- It cannot understand context, tone, or whether a phrase is intentional — review every match yourself.
- The page itself is never edited; results appear only in the popup.
- 100% local, zero network, no data leaves your machine.
