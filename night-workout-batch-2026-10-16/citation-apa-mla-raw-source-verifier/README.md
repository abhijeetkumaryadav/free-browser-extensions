# Citation Builder: APA / MLA / Chicago

## Honest scope
Builds **APA 7th, MLA 9th, and Chicago 17th (author–date)** citations from metadata
**you** enter, and runs a format checker for common mistakes (missing fields,
non-4-digit years, ALL-CAPS titles, incomplete authors, URL without scheme).
It does **not** verify whether a source's claims are true — the popup states this.
Always double-check against the official style manual for final submissions.

## Use
1. Pick the source type (Book / Journal article / Website).
2. Enter authors (one per line: `Last, First`), year, title, container, etc.
3. Click **Build citations** — copy any style with the Copy button.

Your last form is saved locally so the popup can be closed and reopened.

## Privacy
- 100% local — no network calls, no analytics.
- Permission: `storage` only (to remember your form).
