# Lead Record Keeper

**What it does:** Manual B2B lead record keeper. Add leads with company, size,
industry, revenue, location, contact name/email, and notes. Search/filter your
leads, export to CSV, import CSV back.

**Honest scope (important):**
- This is **your data only — NOT enriched** from any source. No API calls, no
  lookups, no data vendors. Everything here was typed or imported by you.
- All data stays in `chrome.storage.local`. Zero network calls.

**Permissions:** `storage` only.
