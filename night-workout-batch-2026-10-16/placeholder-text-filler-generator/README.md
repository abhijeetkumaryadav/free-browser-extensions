# Lorem Forge — Placeholder Text Filler Generator

Generate filler copy for mockups, layouts, and prototypes.

## What it does

- **Three units:** paragraphs, sentences, or words — with a count up to 100.
- **Two flavors:**
  - *Classic lorem* — traditional Latin-flavored placeholder text (optionally
    starting with the iconic "Lorem ipsum…" opener).
  - *Startup ipsum* — buzzword-heavy filler for pitch-deck mockups.
- **Live preview** with word/sentence counts.
- **One-click copy** to the clipboard (with a manual-select fallback if the
  browser denies clipboard access).
- Remembers your last settings.

## Honest scope

Generates filler text locally — nothing leaves your machine. It's placeholder
copy, not real content: don't ship it in production.

## Permissions

`clipboardWrite`, `storage` — copy + remembering preferences. No network, no
page access.

`manifest.json`, `popup.html`, `popup.css`, `popup.js`, `README.md`,
