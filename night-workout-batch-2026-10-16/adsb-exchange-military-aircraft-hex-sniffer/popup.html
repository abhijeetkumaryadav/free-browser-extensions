How Mode-S hex codes work
  • 24-bit ICAO address: every Mode-S transponder broadcasts a unique 6-hex-digit code (e.g. A4B5C6).
  • Country blocks: the first digits identify the country of registry — e.g. A… = USA, 4… = Germany, 39… = Italy, 7C… = Australia.
  • Not a callsign: the hex code identifies the airframe, not the flight — callsigns come from separate ADS-B messages.
  • Military codes use specific registry blocks (e.g. US military AE… range) but reveal nothing about mission or position on their own.

Type a 6-digit hex code — its country block is detected automatically.
