# Chapter Log — Web Novel Reading Tracker

**Your reading log — not a crawler.** You add chapters yourself (novel, chapter number, optional URL, read status, note). Nothing is crawled, compiled, or fetched automatically. All data stays in `chrome.storage.local`; nothing is uploaded.

## Features
- Add chapters with novel title, chapter number, status (to-read / reading / read), optional URL, and note
- Per-novel progress bars with read/total counts
- Search across novels, notes, and chapter numbers
- Export / import as JSON
- Click-through links open the chapter URL in a new tab (you visit them yourself)

## Permissions
- `storage` — save your log locally

## Privacy
Fully local. No network calls, no analytics, no tracking.
