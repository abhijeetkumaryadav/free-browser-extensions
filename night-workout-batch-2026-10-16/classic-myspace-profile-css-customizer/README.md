# MySpace Themer — Personal Site CSS Customizer

Theme any website your way. Per-site custom CSS with fun presets, including a
**MySpace Retro** look (hot pink on dark purple, Comic Sans energy, ridge-bordered images).

## Honest scope

- Themes **YOUR view** of a site only. Nothing is uploaded, shared, or permanent.
- Remove the theme any time — the page is fully restored.
- MySpace itself is long gone; this is retro fun applied to modern sites.

## How to use

1. Open any normal web page and click the extension.
2. Pick a preset (chips load it into the editor) or write your own CSS.
3. **Apply theme** — saved per-domain, reapplied when you click Apply again.
4. **Remove theme** — deletes the saved CSS and restores the page.

## Privacy

- 100% local. Only permission use: `storage` (your saved themes), `activeTab` + `scripting` (inject the style tag on click).
- No network requests, no analytics.
