# Pilot Logbook — Block Time & CSV

A personal pilot logbook: log flights with date, route, aircraft, block time, and landings. See running totals (flights, hours, landings) and export or import everything as CSV. **Your logbook — an unofficial record, not a certified logbook.**

## Features

- Log flights with date, aircraft, route, block hours, landings, notes
- Totals bar: flights, hours, landings
- Export to CSV (download), import from CSV (appends)
- Quoted-field-safe CSV parsing (embedded commas/quotes)

## Limitations

- Unofficial record only — not a substitute for a certified logbook
- Fully local (chrome.storage), zero network
