FITS concepts (quick guide)
  • Header + Data Units: a FITS file is a stack of blocks, each with an ASCII header of KEYWORD = value cards plus optional binary image/table data.
  • BITPIX: bits per pixel (e.g. 16 or -32 float) — sets the data's numeric range.
  • BZERO / BSCALE: physical value = BZERO + BSCALE × stored value.
  • Stretching: raw frames are mostly near-black; min/max cut levels and log stretches reveal faint signal — exactly what the sliders above do.
