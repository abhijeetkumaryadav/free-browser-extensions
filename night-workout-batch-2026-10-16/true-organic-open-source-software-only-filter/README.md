# Open-Source Directory — Curated OSS Finder

Your personal curated directory of open-source software.

## Honest scope

**Your directory — not store filtering.** This extension does not scan, filter, or
modify any app store, marketplace, or website. You add each entry yourself; it is
your own reference list. Entries are stored only in your browser
(`chrome.storage.local`) — nothing is uploaded anywhere.

## Features

- Add software entries: **name**, **category**, **license**, **URL**, and **your notes**
- Case-insensitive **search** across names, categories, licenses, and notes
- **Export / import** your directory as JSON (handy for backups or sharing)
- URL validation — only `http(s)` links accepted; entries capped at 500

## Permissions

- `storage` — saves your directory entries locally. Nothing else.

## Privacy

Fully offline. No network calls, no analytics, no telemetry.
