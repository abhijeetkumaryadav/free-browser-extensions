# Bookmark Dungeon Crawler

A tiny dungeon-crawler game built from **your** bookmarks.

## Honest scope
**Your bookmarks — not a sitemap crawler.** Each of your bookmarks becomes a room.
Nothing is crawled, downloaded, or fetched — doors only open pages you choose to visit.

## How to play
- WASD or arrow keys to walk through rooms and corridors
- Stand inside a numbered room and press **E** to open that bookmark
- Your position is saved locally between visits

## Privacy
- Reads your bookmark list (requires the `bookmarks` permission) — only to build the map, locally.
- No network calls. No data leaves your browser.

## Install
1. Open `chrome://extensions` (or `edge://extensions`)
2. Enable Developer mode
3. Load unpacked: select this folder (or the extracted zip)
