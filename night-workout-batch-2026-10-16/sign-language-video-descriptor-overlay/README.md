# Sign Practice Cards

Personal sign-language practice card set for the Chrome extension marathon.

## Honest scope

**This is a flashcard deck you build yourself. It does NOT recognize signs.**
There is no video analysis, no camera access, no AI. You write each card's
hand-motion description in your own words, optionally paste a reference video
link, and review with flip-cards. It helps you practice — it cannot see or
identify signing.

## Features

- **Flip-card review** — click to flip, arrow keys to move, shuffle
- **Category filter** — practice greetings, food, travel… your call
- **Add card** — sign name, category (or new), motion description in your words,
  practice notes, optional reference video link
- **Deck tab** — search across names/categories/descriptions, delete
- **Mastery tracking** — mark cards "I know this", per-filter progress bar
- All data in `chrome.storage.local`, 100% local, zero network

## Permissions

- `storage` only — your deck.
