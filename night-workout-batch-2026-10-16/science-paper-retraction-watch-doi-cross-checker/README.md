# Paper Logbook — Retraction Watch (Personal)

A personal logbook for papers you want to keep an eye on. Log a DOI and title,
tag it with **your own status** (OK / Concerned / Retracted-by-you), add notes,
search, and track counts.

## Honest scope

- **Your logbook — not live retraction data.** This extension does not query
  Crossref, Retraction Watch, or any journal database. There is no network access.
- Statuses are your own labels, not official retraction verdicts. Always verify
  with the journal or Retraction Watch before citing or sharing.

## Features

- Add papers with DOI (format-validated), title, status, and notes
- Search across DOI / title / notes
- Status counts at a glance
- Delete entries; everything newest-first

## Tech

- Manifest V3, `storage` permission only, fully local.
