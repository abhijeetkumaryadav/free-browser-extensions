# Dead Website Graveyard Walker

## What it is (honest scope)
A **manual memorial list** for websites that died. You record the name, URL, year of
death, and a eulogy for each fallen site. The popup shows a moonlit graveyard doodle
(stars, moon, drifting fog) where each burial gets a tombstone — click one to read
its eulogy.

**Your memorial list — manual.** Nothing is checked automatically: the extension
never pings URLs or decides whether a site is dead. You record the deaths yourself.

## Features
- Bury dead sites: name, URL, year of death, eulogy
- Animated moonlit graveyard canvas with tombstones (click for eulogy)
- Search the fallen, groundskeeper notes (autosaved)
- Everything in `chrome.storage.local`

## Permissions
- `storage` — save graves and notes locally

## Privacy
Zero network. Fully local.
