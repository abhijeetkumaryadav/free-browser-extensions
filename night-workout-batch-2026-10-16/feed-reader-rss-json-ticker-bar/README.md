# Feed List — Personal RSS & JSON Feed Manager

Your personal list of RSS/JSON feeds, with manual article notes per feed.

## Honest scope

**Your feed list — not a live reader.** This extension saves the feed URLs you add
and lets you keep your own article notes per feed, but it **never fetches the
feeds** (browser CORS rules make cross-origin feed fetching unreliable, so it
isn't attempted). Add feeds manually, track what you read yourself, export a
backup anytime.

## Features

- Save feed URLs with a name and **RSS / JSON** type label
- **Manual article notes** per feed (title + text, newest-first, per-note delete)
- Case-insensitive **search** across feed names, URLs, and notes
- **Export / import** as JSON (backup or move between machines)

## Permissions

- `storage` — saves your feeds and notes locally. Nothing else.

## Privacy

Fully offline. No network calls, no analytics, no telemetry.
