# Parked Domain Spotter — Educational Red-Flag Guide

## What it is (honest scope)
An educational guide to the red flags of abandoned / parked domains, plus your own
suspicious-domain notes log. It teaches you what parked pages look like and lets you
keep personal notes about domains you've seen.

## What it does NOT do
- It does **not** check whether any domain is parked, live, or registered.
- It makes **zero network calls** — nothing here contacts the internet.
- "Educational only — not detection" is stated prominently in the popup.

## Features
- 8 red-flag cards describing parked-page patterns (ad-link walls, for-sale banners,
  look-alike typos, missing navigation, redirect chains).
- Quick-habits checklist for trusting a site.
- Personal notes log: domain + title + observations, search, per-note delete,
  clear-all with confirm. Stored only in `chrome.storage.local`.

## Privacy
Fully local. No analytics, no network, no data leaves your browser.

## Test
Headless engine tests: 10/10 pass (note validation, newest-first immutable sort,
case-insensitive filter, guide card count/shape).
