# Tab Grouper — Rule-Based Tab Mesh

One click organizes your tabs into Chrome tab groups. **Honest scope:** grouping
is purely **rule-based** — matches tabs by domain and by your own keyword rules.
No AI, no semantic understanding.

## Features

- **Group tabs now** — keyword rules first (your custom names), then domain
  grouping for leftovers (2+ tabs per domain)
- **Keyword rules** — add rules like `Work → github, stack, jira`; any tab whose
  URL or title contains a keyword joins that group
- **Ungroup all** — one click dissolves every group
- Options: group by domain on/off, current window only on/off
- Pinned tabs are never moved. Fully local, zero network.

## Permissions

- `storage` — persist rules + options
- `tabs` + `tabGroups` — query tabs and create/manage tab groups
