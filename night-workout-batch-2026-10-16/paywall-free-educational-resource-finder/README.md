# Free Learning Logbook

A logbook of **free** educational links — courses, docs, tutorials, videos, books.

## What it does

- Ships with a starter list of well-known, officially free resources (Khan Academy, MIT OCW, MDN, …).
- You save your own links with a topic, type, and star rating.
- Search across everything; filter by topic; remove entries anytime.

## Important: no paywall bypass

This extension **never bypasses paywalls**. It only stores links *you* save — official free resources and links you find yourself. If a site requires a subscription, respect that and use its official access options.

## Privacy

- 100% local (`storage` only), zero network, no remote libraries.
