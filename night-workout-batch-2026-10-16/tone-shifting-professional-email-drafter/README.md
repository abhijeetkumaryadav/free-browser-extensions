# Tone Shift — Email Drafting Toolkit

Draft emails with a **tone toolkit**: pick a target tone (formal / friendly /
firm / apologetic), write your draft, and get bundled phrase-swap suggestions
plus a per-tone checklist to run through before sending. Saved drafts live in
`chrome.storage.local`.

## Honest scope

- **No AI.** There is no rewriting engine and no network. Suggestions are
  bundled templates; the extension never rewrites your email for you — it only
  shows clickable phrase swaps and checklists that *you* apply manually.
- Everything is local: drafts and settings never leave your machine.

## Features

- Target-tone picker (formal, friendly, firm, apologetic)
- Draft textarea with phrase-swap detection — click a suggestion to insert it
  at the cursor
- Per-tone sending checklist (greeting, softeners, sign-off, deadlines…)
- Saved drafts with load / delete, persisted locally

## Permissions

- `storage` — save drafts only.
