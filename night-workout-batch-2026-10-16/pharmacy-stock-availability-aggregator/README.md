# Pharmacy Stock Diary

A personal diary of pharmacy stock observations — log what you saw on the shelf (item, pharmacy, in/out/low stock, date, note) and search your own history later.

## Honest scope

- **Your observations only.** This extension stores exactly what you type — it does **not** check real pharmacy stock. There is no live pharmacy data here; no pharmacy APIs were used.
- 100% local, zero network calls, works offline.

## Features

- Log entries with item name, pharmacy, status (in / out / low stock), and optional note
- Newest-first timeline with per-status color dots
- Search across items, pharmacies, and notes
- Export everything as JSON
- Delete single entries or clear all

## Permissions

| Permission | Why |
|---|---|
| `storage` | Keep your diary entries locally |
| `downloads` | Export your diary as a JSON file |

## Install

1. Open `chrome://extensions` (or `edge://extensions`)
2. Enable **Developer mode**
3. Click **Load unpacked** and select this folder
