# Drone Airspace Guide — No-Fly Notes

An educational drone airspace guide (controlled airspace, LAANC concept, common restrictions) plus your own no-fly zone notes, all stored locally.

## What it does

- **Airspace basics**: plain-language reference on controlled airspace, LAANC-style authorization concepts, common restrictions, height rules, line of sight
- **My no-fly notes**: save areas you personally avoid, with reasons and search

## Honest scope

**Educational only — not live TFRs.** Nothing is fetched; no live temporary flight restriction data is shown. Always check official sources before flying.

## Permissions

- `storage` — persists your notes locally.
