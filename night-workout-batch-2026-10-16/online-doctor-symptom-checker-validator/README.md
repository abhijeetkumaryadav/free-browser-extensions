# Symptom Journal for Doctor Visits

A personal **symptom journal** — you log symptoms with date, severity (1–10),
and notes, then export the log as JSON to share with your doctor.

## Deliberate, honest scope

- **Journal only.** It stores what *you* type: symptom name, date, severity, notes.
- **Never assesses, diagnoses, or validates anything.** There is no symptom
  checker, no condition lookup, no triage, no "likely causes".
- **Not medical advice.** The popup always shows this banner:

> ⚠️ Not a diagnosis — see a doctor. This journal never assesses, diagnoses, or validates symptoms.

If you have a medical concern, see a doctor.

## Features

- Log symptom entries with date, 1–10 severity, and free notes
- Newest-first timeline with search
- Delete individual entries or clear all
- Export a JSON file to bring to your doctor visit

## Privacy

- 100% local — entries live in `chrome.storage.local`
- No network calls, no accounts, no tracking

## Permissions

- `storage` — save your entries locally
