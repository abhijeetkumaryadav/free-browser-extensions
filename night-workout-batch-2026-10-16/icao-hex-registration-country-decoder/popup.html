What is a Mode-S hex code?

A 24-bit ICAO address permanently assigned to an aircraft's transponder. Unlike a flight number, it doesn't change between flights. ICAO allocates address blocks by country, so the first hex digits tell you where the aircraft is registered.

  • Codes start with A → United States block
  • Codes starting 4 → mostly European blocks
  • Codes starting 7 → Asia–Pacific blocks

Educational only — no live tracking, no receiver, no positions. This extension never contacts the network; the prefix table is bundled in the code.
