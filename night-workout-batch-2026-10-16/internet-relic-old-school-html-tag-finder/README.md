# Relic Tags — Old-School HTML Reference

An educational reference of old-school HTML tags (`<marquee>`, `<blink>`, `<font>`…) with plain-language descriptions, status badges (Obsolete / Deprecated / Still alive), a fun 8-question fossil quiz, and your own notes.

## Honest scope

**Educational — not live.** All relics are bundled in the extension; nothing here scans web pages. Zero network calls.

- Browse 16 bundled relics with descriptions and code examples.
- Case-insensitive search.
- **Fossil quiz:** 8 shuffled multiple-choice questions, best score saved locally.
- Personal notes log with search and delete.

## Permissions

- `storage` — saves your notes and quiz best score locally in `chrome.storage.local`.

## Privacy

Everything stays on your device. No data leaves the extension. No accounts, no tracking, no remote code.
