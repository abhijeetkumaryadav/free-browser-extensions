# Sky Sighting Journal

A personal logbook for unusual sky sightings — date, location, shape, description — with search and shape filtering. All local, zero network.

## What it does

- **Log sightings**: date, location, shape (7 categories), free-text description
- **Search & filter**: full-text search across descriptions/locations, shape filter
- **Stats**: sightings per shape as chips
- **Delete / clear-all** with confirmation

## Honest scope

**Your logbook only — educational.** This extension does not query any public database. It only records the sightings you type in, stored in `chrome.storage.local`.

## Permissions

- `storage` — persists your logbook locally.
