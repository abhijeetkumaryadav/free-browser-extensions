# Pacing Timer — Shot Boundary Duration Counter

Pacing analysis for local video files. Mark shot boundaries yourself (tap **Mark boundary** / press **M**) or run **Auto-detect**, which flags scene changes with an average-luminance-delta heuristic sampled through a hidden canvas. Shows a shot list with durations plus average / shortest / longest shot.

**Honest scope:** heuristic markers only — not AI shot detection. Everything runs locally in the popup on your own video file; nothing is uploaded or stored (only your sensitivity settings are saved).

## Use

1. Drop a video file onto the player or click **Choose video**.
2. Press play, tap **Mark boundary** (or **M**) at each cut, or click **Auto-detect** to scan the whole file automatically.
3. Read durations in the shot list; hover the top markers for timestamps.
4. Tune sensitivity / sample interval under *Detection settings*.
