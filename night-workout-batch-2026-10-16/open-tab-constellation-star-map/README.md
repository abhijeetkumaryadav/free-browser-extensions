# Tab Constellation Map

A playful, fully local star-map doodle of your open tabs.

## What it does

- Renders every tab in the current window as a star on a canvas sky.
- Tabs from the same domain are linked into a "constellation" and share a color.
- Hover a star to see the tab title; **click a star to focus that tab**.
- Refresh button re-reads your tabs.

## What it does NOT do

- **Cosmetic only — click-to-focus.** Tabs are never modified, closed, rearranged, or sent anywhere. The map is a doodle; nothing about "constellations" is a real analysis.

## Permissions

- `tabs` — read tab titles/IDs in the current window so they can be drawn and focused.

## Privacy

Zero network. Everything stays on your device.
