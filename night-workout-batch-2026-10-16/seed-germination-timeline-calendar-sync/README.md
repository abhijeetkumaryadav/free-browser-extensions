# Seed Germination Timeline & Calendar Sync

Plan your sowing season right in your browser. Pick seed varieties, set a sowing date,
see the full sow → germinate → harvest timeline, and export every milestone as a
`.ics` calendar file you can import into Google Calendar, Apple Calendar or Outlook.

## Features

- **20-seed local database** — germination ranges, minimum soil temperature, sowing
  depth, spacing, days-to-harvest and indoor-start guidance, all bundled locally
  (standard published gardening figures; labeled as estimates).
- **Visual milestone timeline** — sow, transplant (where applicable), germination
  estimate and harvest estimate on one bar.
- **My plan list** — collect multiple seeds and sowing dates.
- **One-click `.ics` download** — sow, germination, transplant and harvest events
  for every planned seed, generated entirely in the extension.

## Install (developer mode)

1. Open `chrome://extensions`, enable **Developer mode**.
2. **Load unpacked** → select this folder.

## Permissions

- `storage` — remembers your plan list between sessions.

## Honest scope

- Germination figures are typical published ranges, not guarantees; actual results
  depend on cultivar, soil, weather and seed age.
- The extension is 100% local: no network calls, no accounts, no telemetry.
