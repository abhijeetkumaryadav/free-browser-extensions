# Perseverance Journal — Mars Milestones & Logbook

An educational timeline of NASA's Perseverance rover mission with a personal
touch: your own notes on every milestone plus a free-form sol logbook.

## What it does

- Bundled timeline of key Perseverance milestones (launch, landing,
  Ingenuity's flights, MOXIE oxygen demo, sample caching, crater-rim campaign)
- Per-milestone notes field, autosaved locally
- Personal logbook: write dated entries (optional sol number), newest first,
  deletable
- All data in `chrome.storage.local`

## What it is NOT

**Educational — not live telemetry.** There is no NASA API feed, no live
mission data, and no network access at all. The timeline is a fixed set of
well-known mission facts; everything you add is your own writing.

## Permissions

- `storage` — save your notes and logbook

No data ever leaves the browser.
