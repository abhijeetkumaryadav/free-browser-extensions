# Internet Traffic Globe — Simulated Visualizer

An animated globe doodle with simulated "internet traffic" arcs.

## Honest scope
**Simulated — not live data.** Every arc is randomly generated locally in your browser.
Nothing here measures, monitors, or represents real internet traffic.

## What it does
- Rotating wireframe globe with decorative city markers
- 6 randomly generated "routes" between cities with animated packet dots
- Pause/play, speed control, regenerate routes
- A short explainer on how real internet traffic works (packets, undersea cables, routers)

## Privacy
- Fully local. No network calls, no permissions, no data collection.

## Install
1. Open `chrome://extensions` (or `edge://extensions`)
2. Enable Developer mode
3. Load unpacked: select this folder (or the extracted zip)
