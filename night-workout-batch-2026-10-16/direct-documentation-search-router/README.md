# Docs Search Router

Type a query once, open it on every documentation source you pick.

**Honest scope:** this extension *opens doc-search pages* in background tabs — it does **not** search inside those sites for you. Each site runs its own search once the tab opens.

## Sources

Bundled defaults: MDN Web Docs, Stack Overflow, DevDocs, Python Docs, React Docs.
Add your own with any search URL containing `{q}` as the query placeholder.

## Permissions

`storage` — remembers your source list and selections. Nothing else.
