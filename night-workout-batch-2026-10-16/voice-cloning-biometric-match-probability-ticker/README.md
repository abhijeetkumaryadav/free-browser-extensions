# Voice Cloning Awareness — Biometric Match Guide

An educational explainer of how voice cloning works, its red flags, consent norms, and verification habits — plus a personal notes log.

> **Educational only — not biometric matching.** This extension performs no audio analysis and matches nothing. It explains the technology, lists red flags, describes verification habits (call back on a known number, use a family code word), and stores your personal notes locally.

## Features

- **How It Works tab** — plain-language explanation of voice cloning, consent and misuse notes, verification habits.
- **Red Flags tab** — 8 red-flag cards (flat delivery, metallic sibilants, unnatural pacing, timbre shifts, background cut-outs, urgency+secrecy, unverifiable caller, wrong details) with a clear note that flags are only signals.
- **My Notes tab** — personal notes log, newest-first, with delete. Fully local.

## Privacy

- Permissions: `storage` only.
- No network requests. No audio recording. No analytics. No remote code.

## Install (developer mode)

1. Open `chrome://extensions` (or `edge://extensions`).
2. Enable "Developer mode".
3. Click "Load unpacked" and select this folder.

## Limitations

This is an awareness tool. It cannot detect cloned voices, verify callers, or authenticate audio. If you receive an unexpected urgent voice message asking for money, treat it as suspicious regardless of what any tool says.
