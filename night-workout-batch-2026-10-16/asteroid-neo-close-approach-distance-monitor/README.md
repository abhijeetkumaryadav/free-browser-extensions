# NEO Close-Approach Journal

A fully local journal for asteroid close approaches you log yourself.

## What it does

- Log approaches: asteroid name, date/time, miss distance in **lunar distances**, size estimate, notes
- Live countdown to the next upcoming approach (updates every second)
- Upcoming list (soonest first) and past list with per-entry delete
- Distances shown in LD with an approximate km conversion

## Honest scope

**Your entries only — not live NEO data.** This extension does not fetch data from
NASA CNEOS or any catalog; it only tracks what you type. It is educational and is
not an official prediction source.

## Permissions

- `storage` — save your journal entries locally. Nothing else.

## Privacy

Zero network. Nothing leaves the browser.
