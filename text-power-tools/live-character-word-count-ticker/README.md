# WordTicker — Live Character & Word Counter

Type or paste text and watch live counters: words, characters (with/without spaces),
sentences, paragraphs, estimated reading time, top-5 keyword density, and a word-goal
progress bar. Your draft autosaves locally.

## Install (Chrome / Edge / Opera)

1. Unzip `live-character-word-count-ticker.zip`.
2. Open `chrome://extensions`, enable **Developer mode**.
3. Click **Load unpacked** and select the unzipped folder.

## Install (Firefox)

1. Open `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on**.
2. Select `manifest.json` inside the unzipped folder.

## Permissions

- `storage` — saves your draft text and word goal on-device only. Nothing is sent anywhere.

## Publishing notes
