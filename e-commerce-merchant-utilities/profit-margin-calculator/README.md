# Profit Margin Calculator v1.0.0

Deep margin math for sellers: enter unit cost, sell price,
marketplace fee %, ad spend per unit, and shipping — get **net
profit per unit**, **net margin %**, **breakeven ROAS**, and **max
allowable ad spend**, plus a verdict badge (EXCELLENT → LOSING
MONEY). Save named scenarios, reload them into the calculator,
and delete them. All on-device.

Breakeven ROAS = price ÷ (price − fee − cost − shipping): the ad
efficiency at which profit hits exactly zero.

## Try it
1. Unzip `profit-margin-calculator.zip`.
2. `chrome://extensions` → Developer mode → **Load unpacked** → select folder.
