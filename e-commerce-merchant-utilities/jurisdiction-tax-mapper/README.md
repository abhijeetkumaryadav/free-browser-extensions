# Jurisdiction Tax Mapper v1.0.0

Estimate sales tax, VAT, and GST: enter an amount, pick a
jurisdiction, see base / tax / total breakdown. Supports
tax-inclusive reverse calculation. Ships with sample rates
(India GST slabs, US states, UK/EU VAT, UAE, Singapore) — add your
own jurisdictions, which persist on-device.

Sample rates are for quick estimates — always verify against
current local rules before filing.

## Try it
1. Unzip `jurisdiction-tax-mapper.zip`.
2. `chrome://extensions` → Developer mode → **Load unpacked** → select folder.
