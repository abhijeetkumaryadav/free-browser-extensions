# Negotiation Margin Helper v1.0.0

Supplier negotiation calculator. Enter **list price**, **your target
price**, and **walk-away price** (optionally your resale price): it
builds a 3-round counteroffer ladder — aggressive anchor, midpoint
counter, final target — showing discount-vs-list and margin impact at
every rung. Never crosses your walk-away. Save scenarios for later.

## Try it
1. Unzip `negotiation-margin-helper.zip`.
2. `chrome://extensions` → Developer mode → **Load unpacked** → select folder.
