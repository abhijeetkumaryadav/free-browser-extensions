# Inventory Multi-Syncer v1.0.0

One stock table for every marketplace. Add SKUs with low-stock
thresholds, adjust quantities with steppers, get color-coded
low/out-of-stock status, and export per-marketplace quantity CSVs
(Amazon / eBay / Shopify headers) plus a full CSV. Import existing
CSVs too. Everything on-device.

## Try it
1. Unzip `inventory-multi-syncer.zip`.
2. `chrome://extensions` → Developer mode → **Load unpacked** → select folder.
3. Click the icon, add SKUs, export when ready.
