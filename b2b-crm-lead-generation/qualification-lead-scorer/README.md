# Qualification Lead Scorer v1.0.0

Score sales leads with BANT criteria (Budget, Authority, Need,
Timeline) on 0–10 sliders, plus free-text fit notes. Produces a
0–100 score with a HOT / WARM / COLD verdict (Need counts double —
a real problem to solve is the strongest buying signal). Save
leads to a local history with per-factor bars and delete.

## Try it
1. Unzip `qualification-lead-scorer.zip`.
2. `chrome://extensions` → Developer mode → **Load unpacked** → select the folder.
3. Click the icon, score a lead, save it.

Firefox: `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on** → pick `manifest.json`.
Edge: same as Chrome via `edge://extensions`.
