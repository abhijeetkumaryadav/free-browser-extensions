# Bidding Portfolio Assistant v1.0.0

Ad budget assistant with manual entry: add campaigns (name, avg CPC,
daily budget, conversions, revenue) and get a portfolio summary with
per-campaign ROAS badges, money-losing and trailing-performance
alerts, and a suggested budget reallocation (10% from underperformers
to the best-ROAS campaign, with projected extra return).

## Try it
1. Unzip `bidding-portfolio-assistant.zip`.
2. `chrome://extensions` → Developer mode → **Load unpacked** → select folder.
3. Click the icon, add campaigns, review the suggestions.
