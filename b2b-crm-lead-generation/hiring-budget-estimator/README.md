# Hiring Budget Estimator v1.0.0

Fully-loaded hiring cost planner. Enter **base salary, benefits %,
payroll tax %, recruiting fee %**, plus **equipment** and
**onboarding** one-offs → get the true **year-one cost per hire**,
the **monthly run-rate**, and a full breakdown. Add multiple roles
for a **team budget rollup** (total year one, total monthly,
average per hire). All saved on-device.

## Try it
1. Unzip `hiring-budget-estimator.zip`.
2. `chrome://extensions` → Developer mode → **Load unpacked** → select the folder.
3. Click the icon, fill in the role, hit **Calculate & add role**.

## Permissions
- `storage` — saved roles and rollup, on-device. Nothing else needed; no network access.
