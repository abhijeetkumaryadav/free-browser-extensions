# Terms of Service Risk Translator v1.0.0

Paste Terms of Service text and the extension scans it on-device for
six risky clause patterns: binding arbitration, class-action/jury
waivers, data sharing or sale, unilateral termination, auto-renewal,
and liability limitations. Each flag shows a plain-language
translation plus the original quote. One-click report copy.

Clearly labeled as a **heuristic scan — not legal advice**. Always
read the full terms before agreeing.

## Try it
1. Unzip `terms-of-service-risk-translator.zip`.
2. `chrome://extensions` → Developer mode → **Load unpacked** → select folder.
3. Click the icon, paste ToS text → **Scan for risks**.
