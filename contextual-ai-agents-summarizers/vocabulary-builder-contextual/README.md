# Vocabulary Builder Contextual v1.0.0

Save words **with the sentence where you found them**. Three modes:

- **Cards** — flashcards with a smooth 3D flip animation.
- **Quiz** — word shown, you recall the meaning, then self-grade
  ("Knew it" / "Still learning").
- **Add** — word list with seen/score tracking and delete.

Review order is spaced: least-recently-reviewed words come first.
Everything stored on-device.

## Try it
1. Unzip `vocabulary-builder-contextual.zip`.
2. `chrome://extensions` → Developer mode → **Load unpacked** → select folder.
3. Click the icon → **Add** tab → save your first word.
