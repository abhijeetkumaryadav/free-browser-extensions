# Judicial Precedent Finder v1.0.0

Legal research helper. Enter a legal topic + jurisdiction (India, US,
UK, EU, International) and it builds prefilled search launchers for
free public law databases (Indian Kanoon, Justia, CourtListener,
Google Scholar, BAILII, EUR-Lex) — opened in new tabs, nothing
scraped. Includes a case-brief template (facts, issue, holding,
reasoning) you can save per topic, copy, and delete.

Not legal advice — verify citations against primary sources before
relying on them.

## Try it
1. Unzip `judicial-precedent-finder.zip`.
2. `chrome://extensions` → Developer mode → **Load unpacked** → select folder.
3. Enter a topic, pick a jurisdiction, open the launchers.
