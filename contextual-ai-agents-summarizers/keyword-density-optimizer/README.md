# Keyword Density Optimizer v1.0.0

Paste text + a target keyword. Get the density %, total occurrences,
and a beginning / middle / end distribution bar chart, plus a verdict
(under-optimized → ideal → stuffing risk). The SEO checklist
auto-detects what it can (first-100-words placement, 1–2% band, no
stuffing) and lets you tick the rest manually — ticks persist
on-device.

## Try it
1. Unzip `keyword-density-optimizer.zip`.
2. `chrome://extensions` → Developer mode → **Load unpacked** → select folder.
3. Paste an article + keyword, hit **Analyze**.
