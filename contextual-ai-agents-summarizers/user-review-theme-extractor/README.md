# User Review Theme Extractor v1.0.0

Paste customer reviews (one per line) and get an on-device theme
breakdown: recurring topics like battery, shipping, quality, price,
design, performance, ease of use, customer service, and packaging —
each with mention count, a sentiment lean bar (mostly positive /
mixed / mostly negative), and example quotes.

The miner is a **keyword-based heuristic**, clearly labeled in the
popup. A starting point for reading, not AI sentiment analysis.
Nothing leaves your device.

## Try it
1. Unzip `user-review-theme-extractor.zip`.
2. `chrome://extensions` → Developer mode → **Load unpacked** → select folder.
3. Click the icon, hit **Sample** or paste your own reviews, then **Extract themes**.
