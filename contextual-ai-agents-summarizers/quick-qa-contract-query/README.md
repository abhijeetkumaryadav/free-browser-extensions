# Quick QA Contract Query v1.0.0

Paste any contract text, then tap a preset question (Termination,
Payment terms, Liability cap, Renewal, Confidentiality, Governing
law, IP ownership, Disputes) or type your own keywords. The
extension returns the matching passages with surrounding context
and keyword highlighting — pure on-device text search, in
milliseconds. Your text never leaves the browser.

**Not AI. Not legal advice.** This tool finds passages; it does not
interpret them. Always consult a qualified lawyer.

## Try it
1. Unzip `quick-qa-contract-query.zip`.
2. `chrome://extensions` → Developer mode → **Load unpacked** → select the folder.
3. Paste contract text, tap a question chip.

## Permissions
- `storage` — saves your pasted text locally so it's there next time.
