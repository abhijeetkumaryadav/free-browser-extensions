SheetsReady

Tables → Google Sheets, no API needed

Reads <table> elements on the current tab only, when you click scan. Nothing is modified.

  1. Pick a table above (or paste one).
  2. Click Copy TSV — TSV pastes perfectly into Google Sheets.
  3. In Google Sheets, click cell A1 and press Ctrl/⌘ + V.
  4. Or click Download CSV and use File → Import in Sheets.

SheetsReady has no Google integration — it prepares clean copy-paste / import-ready files. Your data never leaves this device.
