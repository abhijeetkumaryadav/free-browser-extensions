# ReplySmith — Email Reply Drafter

Assemble polished email replies from editable sentence blocks. Paste an incoming email, pick a tone (professional / friendly / firm / apologetic) and an intent (accept / decline / follow up / thank), and get a structured reply with greeting, body, and closing blocks — every word editable before you copy it to your clipboard. Save up to 20 drafts and recall your last-used tone/intent automatically.

**Template-based — not AI.** No model, no API, no network calls. Everything is assembled locally from sentence templates and stays on your device.

## Install
- Chrome / Edge: unzip, open `chrome://extensions`, enable **Developer mode**, **Load unpacked**, select this folder.
- Firefox: open `about:debugging#/runtime/this-firefox`, **Load Temporary Add-on**, select `manifest.json`.
- Opera: enable developer mode in extensions, load unpacked.

## Permissions
- `storage` — saves your last-used tone/intent and up to 20 saved drafts, all on-device.
