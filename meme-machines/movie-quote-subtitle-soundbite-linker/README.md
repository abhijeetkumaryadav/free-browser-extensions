# QuoteVault — Cinematic Quote Library

A curated quote library with two clearly-labeled sections:

- **Original lines** (14) — cinematic-style lines written for this extension. They are **not** actual film quotes; labeled as such everywhere.
- **Public domain** (14) — genuine public-domain quotes (Shakespeare, Austen, Dickens, Brontë, historic speeches).

Features: live search across quotes and authors, category chips (All / Original lines / Public domain / Starred), click any card to copy the quote, star favorites that persist on-device.

No network calls, no copyrighted material, everything stays on-device.

## Install (Chrome / Edge / Opera)

1. Unzip `movie-quote-subtitle-soundbite-linker.zip`.
2. Open `chrome://extensions` and enable **Developer mode**.
3. Click **Load unpacked** and select the unzipped folder.

## Install (Firefox)

Load via `about:debugging → This Firefox → Load Temporary Add-on`. Only uses `storage`, fully Firefox-compatible.

## Permissions

| Permission | Why |
|---|---|
| `storage` | Persist your starred favorites on-device. |

No host permissions, no remote code, no analytics.
